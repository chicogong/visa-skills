## 核心知识库

### 泰国签证核心规则
- **免签政策**：目前对中国籍普通护照开放单次最高30天的免签入境（旅游目的）。
- **TDAC**：2025年起所有外国旅客必须在入境前72小时内填写数字入境卡(TDAC)。
- **现金抽查**：入境需携带足额现金（每人2万泰铢，家庭4万泰铢或等值外币），信用卡不计作证明。

### 材料清单（免签入境必备）

| 材料 | 重要性 | 关键要求 |
|---|---|---|
| 护照 | ✅ 必须 | 有效期6个月以上 |
| TDAC 电子入境卡 | ✅ 必须 | 入境前72小时内在线填写并保存QR Code |
| 离境机票 | ✅ 必须 | 30天内离境的行程单 |
| 住宿证明 | ✅ 必须 | 酒店预订单 |
| 足额现金 | ✅ 必须 | 每人至少20,000泰铢或等值外币现钞 |

### 高频拒签 / 入境受阻坑点
1. **未填写 TDAC**：未提前填写电子入境卡导致在海关滞留。
2. **未带足现金**：被海关抽查时无法出示足额现金，有被原机遣返风险。
3. **携带违禁品**：如携带电子烟及加热烟，面临重罚。
